# 눈먼 자들의 저택 (팬게임)

웹소설 「괴담에 떨어져도 출근을 해야 하는구나」 속 괴담 「눈먼 자들의 저택」을 바탕으로 팬이 만든 **비공식** 1인칭 탈출 게임입니다. 원작자, 출판사와 관계없으며 상업적 용도가 없습니다.

- 플레이: https://sunlitkoreakorea.github.io/blind-mansion/
- PC 브라우저(크롬, 엣지, 파이어폭스)에서 키보드와 마우스로 합니다.
- 조작: WASD 이동 / Shift 달리기 / E 살펴보기 / F 양초 / Q 렌즈 / R 수리 / 오른쪽 클릭 줌

게임 속 글과 그림, 소리는 모두 새로 만들었습니다. 3D 화면은 [three.js](https://threejs.org/)(MIT, `vendor/LICENSE-three`)를 씁니다.
